Fresh Start in Education

Modular MCAE XHTML Email Template System

Moving from Mailchimp removed the content blocks people relied on. I replaced them with reusable XHTML modules that non-coders could assemble in MCAE.

Marketing Automation Salesforce & CRM Operations AI-Assisted Innovation
Project overview

I took the layouts from the strongest Mailchimp campaigns and turned them into about 13 modules across 13 MCAE templates. They allow up to 48 layouts. After launch, the system was used for around 28 emails in 24 campaigns and cut a typical build from several days to about one.

Key result Created approximately 13 reusable modules across 13 templates, supporting up to 48 combinations and reducing typical production from several days to approximately one day.
Capabilities
  • Modular email architecture
  • AI-assisted XHTML development
  • Responsive email testing
  • Brand and asset governance
  • Documentation and user training
Platforms

01

The production gap after migration

Mailchimp had made branded emails easy to assemble with drag-and-drop blocks. MCAE did not offer the same setup, so equivalent parts had to be coded.

The replacement needed to work on mobile, survive cautious recipient security settings and follow an evolving brand. Most users would never edit the XHTML themselves.

  • Loss of the previous content-block workflow
  • Need for repeatable branded layouts
  • Users without routine code access
  • Strict recipient security environments
  • Mobile and desktop compatibility requirements

02

Starting with emails that had already worked

I reviewed the Mailchimp campaigns associated with the most revenue. Recurring layouts, content structures and visual choices became the first sketches for the module library.

I adapted the useful parts to the current branding. The work also formalised an existing informal voice and identified two additional voices for persona-based marketing.

  • Revenue-led Mailchimp campaign review
  • Layout and content-pattern analysis
  • Initial modular template sketches
  • Brand-system application
  • Persona-supporting creative direction

03

Reusable module architecture

I created about 13 reusable XHTML snippets and stored them inside 13 ready-to-use templates. The set includes banners, text, calls to action, image panels, split layouts and footers.

Images can sit full-width or beside text at several points in the email. The modules allow up to 48 calculated combinations; roughly 20 to 30 have been used. The team does not need a new template for every campaign.

  • Hero-banner and text modules
  • Call-to-action and image-panel modules
  • Split image-and-text table layouts
  • Reusable footer structures
  • Up to 48 calculated combinations

04

Directed AI-assisted XHTML development

I specified each module's layout, behaviour, brand rules and editable areas before using Gemini and Claude Code to help write the XHTML.

I reviewed the code, inspected the output, ran test sends and checked the behaviour before release. AI also helped with later debugging. My ownership is of the requirements, judgement, testing and implementation, not a claim that I wrote every complex XHTML line unaided.

  • Detailed module specifications
  • Structured AI development direction
  • Manual XHTML review and interpretation
  • Visual and behavioural validation
  • AI-assisted debugging and compatibility work

05

Compatibility and security-conscious design

I checked the templates in MCAE, then sent them repeatedly to professional Gmail and Outlook inboxes. Testing covered text, images, buttons, links and layouts on desktop and mobile.

The XHTML is deliberately simple and has few dependencies. Images are decorative, so the message, links and actions still work if an inbox blocks them.

  • MCAE editor and repeated test sends
  • Gmail and Outlook rendering validation
  • Mobile and desktop review
  • Minimal dependency design
  • Live-text, image-independent actions

06

Handing the system to everyday users

I organised banners, logos and approved imagery for reuse. Users can combine, reorder and replace module content without touching the XHTML or breaking the approved layout.

I wrote instructions and trained line managers to choose templates, manage images and adapt campaigns. It became the organisation's only standard email-template system and has supported around 28 emails across about 24 campaigns.

  • Reusable brand-asset library
  • Drag-and-drop module assembly
  • Written user instructions
  • Line-manager training
  • Incremental template-library expansion
