Independent Project

AI-Assisted Newsletter Engagement and Privacy-Conscious Leaderboard

I wanted to give newsletter readers a reason to come back that was not another sales message. The result is a short monthly game with an anonymous leaderboard and no need to store names or email addresses.

AI-Assisted Innovation Marketing Automation Data & Analytics Operations
Project overview

ChatGPT helped me produce the first working version in a day. I spent roughly a week and three major versions testing the game, refining the interface and applying the brand before publishing through GitHub and Vercel. It now runs inside the Fresh Start newsletter.

Key result Produced a functioning prototype within one day and a polished, mobile-friendly deployed application within approximately one week.

01

The long-cycle engagement problem

Education-sector purchases can involve up to four buying-committee members and take time. Standard newsletter and sales content did not always give an individual reader much reason to interact between formal buying conversations.

I wanted a repeatable feature that might help readers remember the newsletter and choose to return, while still feeling appropriate for an education brand.

  • Long, multi-stakeholder buying journey
  • Up to four buying-committee members
  • Need for recurring low-friction interaction
  • Newsletter retention and brand recall
  • Education-sector brand alignment

02

Original product and interaction concept

I combined memory, repeating patterns and vocabulary in a simple challenge. Before the build, I set the business purpose, rules, scoring, user experience, monthly competition and privacy approach.

The game resets with the newsletter each month. A later edition can mention the previous high score and continue the competition.

  • Memory and pattern-based interaction
  • Vocabulary-led educational alignment
  • Product rules and score model
  • Recurring monthly newsletter role
  • Continuity between campaign editions

03

Prompt-led rapid prototyping

I used ChatGPT to turn the product rules into a web app. My role was to direct the build through prompts, evaluate the output and test successive versions; I did not manually write the generated code.

The first viable version took a day. Over the following week I refined the interface, game behaviour, leaderboard and branding through three major versions.

  • Structured prompt design
  • AI-assisted application generation
  • Evaluation-led refinement
  • One-day viable prototype
  • Three major product versions

04

Cross-device testing and brand refinement

I tested desktop browsers, mobile phones, different screen sizes, the main interactions, score handling and leaderboard entry. The test findings shaped each version as I went.

I applied the education company's fonts, colours and visual identity so the game looked like part of the newsletter, not an unrelated microsite.

  • Desktop cross-browser testing
  • Mobile-phone and screen-size testing
  • Core interaction validation
  • Leaderboard and score-handling checks
  • Brand-aligned interface refinement

05

Privacy-conscious monthly leaderboard

The app does not need to retain names, email addresses or other identifying information. A participant chooses an available five-letter label for the arcade-style leaderboard.

The leaderboard resets monthly. The newsletter can still recognise the previous winning score without asking anybody to maintain a profile.

  • No retained names or email addresses
  • Anonymous five-letter identifiers
  • Monthly leaderboard reset model
  • Data-minimisation by design
  • Recurring competition without user profiles

06

Publishing, deployment and live use

I published the project on GitHub and deployed it through Vercel after the desktop and mobile tests passed.

It is now live inside the Fresh Start newsletter. External readers can reach it through the free newsletter subscription; there is no separate public page.

  • GitHub version publishing
  • Vercel deployment
  • Completed responsive application
  • Live recurring newsletter integration
  • Accessible through a free subscription
