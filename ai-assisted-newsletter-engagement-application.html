Independent Project

AI-Assisted Newsletter Engagement and Privacy-Conscious Leaderboard

Independently conceived, designed, built, tested and deployed a mobile-friendly web application that transformed newsletter engagement into a recurring memory, pattern and vocabulary experience with an anonymous monthly leaderboard and no requirement to retain personal user data. The application is now live within the Fresh Start newsletter behind a free subscription.

01

The long-cycle engagement problem

The product concept responded to a long and complex education-sector B2B buying journey in which decisions could involve up to four buying-committee members. Conventional newsletter and sales content did not always give individual stakeholders a low-friction reason to keep engaging between formal purchasing conversations.

The objective was to create a repeatable newsletter feature that could support retention, brand recall and individual interaction while remaining aligned with an educational brand rather than operating as a disconnected one-off game.

  • Long, multi-stakeholder buying journey
  • Up to four buying-committee members
  • Need for recurring low-friction interaction
  • Newsletter retention and brand recall
  • Education-sector brand alignment

02

Original product and interaction concept

Created an experience combining memory, pattern repetition and vocabulary to reflect the organisation's educational positioning. Defined the business purpose, product rules, newsletter role, intended user experience, recurring competition model and privacy approach before development.

The application was designed as a monthly newsletter feature rather than a single campaign asset, giving future editions a mechanism for referencing previous high scores and continuing participation.

  • Memory and pattern-based interaction
  • Vocabulary-led educational alignment
  • Product rules and score model
  • Recurring monthly newsletter role
  • Continuity between campaign editions

03

Prompt-led rapid prototyping

Used ChatGPT as an AI-assisted development tool to translate the concept into a functioning web application. Directed development through structured prompts, evaluation, testing and successive refinement rather than manually editing the generated code.

A viable proof of concept was produced within one day. The interface, game behaviour, leaderboard handling and brand treatment were then refined across three major versions over approximately one week.

  • Structured prompt design
  • AI-assisted application generation
  • Evaluation-led refinement
  • One-day viable prototype
  • Three major product versions

04

Cross-device testing and brand refinement

Tested the application across multiple desktop browsers, mobile phones, mobile and desktop screen sizes, core interactions, leaderboard entry, score handling and visual consistency. Findings informed each major version rather than testing being left until the end.

Applied the education company's fonts, colours, visual identity and brand values to create a stakeholder-facing experience that felt connected to the newsletter and wider organisation.

  • Desktop cross-browser testing
  • Mobile-phone and screen-size testing
  • Core interaction validation
  • Leaderboard and score-handling checks
  • Brand-aligned interface refinement

05

Privacy-conscious monthly leaderboard

Designed the application so names, email addresses and other personally identifiable information did not need to be retained. Participants could submit an available, anonymous five-letter identifier to the arcade-style leaderboard.

The leaderboard was designed to reset monthly alongside the newsletter cycle. Future newsletters could reference the previous month's highest score, creating continuity and competition without requiring a persistent personal profile.

  • No retained names or email addresses
  • Anonymous five-letter identifiers
  • Monthly leaderboard reset model
  • Data-minimisation by design
  • Recurring competition without user profiles

06

Publishing, deployment and live use

Published the completed project through GitHub and deployed the functioning application through Vercel. The product was technically complete, mobile-friendly and ready to operate as a recurring newsletter feature.

The application is now live inside the Fresh Start newsletter. Recruiters and other external readers can access the newsletter through its free subscription rather than through an open public page.

  • GitHub version publishing
  • Vercel deployment
  • Completed responsive application
  • Live recurring newsletter integration
  • Accessible through a free subscription
